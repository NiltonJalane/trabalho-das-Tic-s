Soluções e Recomendações

Para usar as redes sociais sem prejudicar a escola:

1. Usar o telemóvel só para estudar quando for hora de estudar.
2. Desligar as notificações durante as aulas e os TPCs.
3. Criar um horário: 1 hora para estudar, depois 20 minutos para redes sociais.
4. Não usar o telemóvel depois das 22h para dormir bem.
5. Usar grupos de WhatsApp só para trabalhos da escola.

Se os alunos seguirem estas regras, as redes sociais vão ajudar e não prejudicar.
